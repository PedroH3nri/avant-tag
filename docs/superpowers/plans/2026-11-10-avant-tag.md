# avant-tag Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pôr no `avant-tag` todo o código que roda no site do cliente. Saem dois scripts: o `tag.js`, que é a ad tag completa com o reward dentro, e o `reward.js`, só com o reward, no mesmo endereço de hoje. O `tag.js` faz tudo o que a g-tag do Genius faz, com os defeitos corrigidos, em menos de 30 KB gzip.

**Architecture:** TypeScript sem framework, em módulos (`core`, `loader`, `ads`, `page-views`, `mgid`, `analytics`, `reward`). Cada módulo recebe as dependências (janela, relógio, rede) por parâmetro, para que os testes rodem com jsdom. O Vite gera um IIFE por entrada (`src/tag.ts` e `src/reward.ts`). O avant-web instala o pacote por tag git, como a API instala o core, e:

- usa o mesmo render na prévia da ad tag, do loader e do reward;
- copia `tag.js` e `reward.js` para o `dist/`, que o nginx já serve.

**Tech Stack:** TypeScript 6, Vite 8, Vitest 5 com jsdom, oxlint, pnpm 10 e Node 26, como no avant-web.

**Decisões:**

- avant-core `docs/decisoes/13-ad-tag.md`;
- plano do loader em `docs/superpowers/plans/2026-11-10-loader.md` (Task 4);
- protótipo em avant-web `design/prototype`.

## Contrato com a API

- **Configuração.** `GET {origem}/api/tag/config?key={chave}&url={location.href}` responde `{"tag": PublicAdTag | null}`. Os tipos são iguais aos de `avant-api/src/avant_api/modules/ad_tag_public/dto.py`: `key`, `version`, `domain`, `lazy_load`, `analytics_id`, `mgid{tag_id, smart_widget, back_button, sidebar}`, `reward`, `price_rules`, `loader` e `blocks[]`. Cada bloco tem `kind`, `unit_type`, `desktop`, `mobile`, `edge`, `selector`, `side`, `refresh_seconds`, `mgid_article`, `rule_mode` e `paths`.
- **Página vista.** `POST {origem}/api/tag/page-views` sai por `sendBeacon` (corpo `text/plain` com JSON), **uma vez por página**, quando a página fica oculta ou é fechada. O corpo leva:
  - `key`, `url`, `page_view_id`, `visitor_id`, `session_id` e `version`;
  - `device` (`desktop` ou `mobile`), `language` e `referrer`;
  - `visible_ms`, `scroll_percent`, `clicked` e `adblock`;
  - `id_post`, `content_hash` e `blocks[{type, state}]`, com `state` `rendered` ou `empty`.
  O IP fica na API e o país é achado no worker.
- **Reward.** `GET /api/reward/v2?url=` mais os eventos e contatos, como hoje no `avant-web/src/embed/reward`.
- **Origem.** É a do `src` do próprio script (`document.currentScript`). A chave vem de `data-tag`.

## Global Constraints

- **Clean code** (skill `avant-clean-code`):
  - nomes claros, nada de nome de uma letra (nem em callback);
  - um `/** */` de 1 ou 2 linhas acima de cada função;
  - nada de comentário ao lado do código;
  - conferido por `pnpm clean-code`.
- **Textos** em português no código; o que aparece ao visitante sai no idioma do navegador.
- **Uma vez por página.** Uma segunda tag ou o `reward.js` junto desistem (`window.__avantTag` e `window.__avantReward`).
- **A página nunca quebra.** Qualquer erro de um módulo fica nele (`try/catch` por módulo), e o loader sempre sai.
- **O GAM é só leitura:** a tag só monta slots.
- **Antes de abrir PR:** `pnpm lint && pnpm clean-code && pnpm typecheck && pnpm test && pnpm build && pnpm size`.
- **Fluxo:** PRs para `pre-develop`, promoção para `develop` com CI verde. A versão sai por tag git (`v0.x.y`), gerada por Action quando o `version` do `package.json` muda na `develop`, como no core.

## Review Focus

1. **Domínio.** A tag só roda se `tag.domain` for o domínio da página. A API já confere, e a tag confere de novo com a cópia do `localStorage`.
2. **Uma página vista, um envio.** Nada de duplicar envio no clique mais saída, como faz a g-tag.
3. **Tablet conta como celular** para os blocos: `matchMedia('(pointer: coarse)')` e largura, além do user agent.
4. **Refresh** só com o bloco 50% visível e a aba aberta, no máximo 5 vezes.
5. **Tamanho do `tag.js`:** menos de 30 KB gzip, conferido no CI.
